# PMT 全流程节点工作流设计草案

状态：用户已确认；实现与操作说明见 `docs/pmt-processing-workflow.md`。

## 目标与现状

将 TIFF 导入、灰度分层、DXF Hatch（含分块）、Machine 和 PMT 放在同一无限画布中，通过连线组织处理流程。继续使用 Avalonia 和现有 Python 加工算法。

现有 LaserPmtWorkflow 主要表达加工来源、参数节点和 PMT 布局，尚未表达上游处理图。PmtDraftSession.CreateMatrixWorkflow 当前从活动来源重建全部 PMT，并清理原 PMT 的连接；需要改成以选中的单个 PMT 为模板创建矩阵。当前画布键盘逻辑尚无复制、粘贴、撤销历史。

## 方案选择

推荐：新增处理图领域层，复用现有 PMT 布局及加工算法。在同一画布显示工具节点和工件容器，处理数据连线与激光参数连线采用不同端口类型。

备选一：直接把上游节点加入现有 LaserPmtWorkflow。初始改动较少，但现有模型要求至少一个机器来源，不适合尚未加工的 TIFF 空项目。

备选二：改为 Web 节点编辑器。图编辑生态较丰富，但会引入额外运行环境以及现有桌面预览、文件操作的迁移成本。

## 画布和节点

- TIFF：拖入文件或通过导入按钮创建纹理节点；显示缩略图、尺寸、DPI 和物理尺寸。
- 灰度分层：输入纹理，设置分层参数，输出有序的分层 TIFF 集合。
- DXF Hatch：接收纹理或分层 TIFF，设置填充及现有 Voronoi 分块参数；输出按层组织的 DXF、分块元数据及预览。
- Machine：接收选定 DXF 层，设置激光、层间进给和块间移动参数，输出可加工来源。
- PMT：引用加工来源、层选择、物理尺寸及参数覆盖；可作为单个加工对象，或作为矩阵模板。

节点标题栏用于移动；空白拖动平移、滚轮缩放，支持适应全部。右侧检查器编辑选中对象。工件容器中的 PMT 使用毫米坐标，图节点使用画布坐标；移动工具节点不会改变加工位置。

## DXF 作为单个 PMT

在 Hatch 输出处提供“创建单个 PMT”。操作自动建立可见的 Machine 节点并连接 PMT，Machine 参数可直接编辑。这样 DXF 可以一键用于单个 PMT，同时保留实际加工所需的参数配置。创建草稿无需立即执行；正式输出前必须完成 Machine 转换及校验。

默认把此次选择的全部层组合为一个 PMT，保留层顺序和分块顺序。用户可分别选择不同层组并创建不同 PMT。

## 全部层与部分层传递

灰度和 Hatch 节点各有“全部层”输出，以及可展开的层列表。勾选一层或多层后，从“选中层”端口拖线；连线显示层数及选择摘要。

选择保存在每条连接上，同一节点可向不同下游传递不同层组。“全部层”随上游结果更新；部分层按稳定层 ID 保存，保持源层顺序。选中层消失时标记连接失效，禁止下游运行，不能静默替换或漏层。

Hatch 的层间角度按源层身份保留，不因挑选子集重新编号。Machine 默认对传入层依序执行层间进给，不自动补齐被跳过层的深度。层与加工块分别建模，选择层时携带其完整分块元数据。

## 从单个 PMT 创建矩阵

选中一个 PMT 后，点击“矩阵工件”，用现有行列选择器预览数量和布局，可设置工件尺寸和间距。建议每次创建独立工件容器：以选中 PMT 为模板生成行×列个实例，原 PMT 保留，其他工件不受影响。

实例继承模板来源、所选层、尺寸、参数覆盖及参数输入连接，获得新的稳定 ID 和不重复编号。实例之间共享加工数据引用；编辑某个实例的覆盖值只影响该实例。上游更新则使依赖它的所有实例待重新计算。

矩阵创建作为一次撤销操作。越界和正面积重叠明确提示并阻止加工输出；边缘接触允许。

## 键盘与编辑历史

支持 macOS Cmd+C / Cmd+V / Cmd+Z / Cmd+Shift+Z，并提供对应 Ctrl 快捷键。输入框聚焦时沿用文本编辑快捷键。

复制单个或多个图节点、PMT 和工件。粘贴分配新 ID，重建选区内连线；PMT 保留有效的来源及参数引用，普通处理节点不隐式复制选区外上游。粘贴位置偏移并选中新对象，缺失输入明确提示。

增加、删除、连线、层选择、参数修改、移动、粘贴和矩阵生成均可撤销与重做。一次连续拖动只记录一条历史。撤销编辑不删除已生成磁盘文件，也不逆转已发布加工包。

## 执行与保存

处理图仅允许类型匹配的无环连接。运行选中节点时，按依赖顺序执行必要上游；支持运行到 PMT 输出及取消。节点显示未运行、处理中、成功、过期或失败状态。

修改输入、参数或层选择时，只使相关下游过期。执行使用固定快照，运行中发生编辑时，旧结果不能标记为当前结果。缓存按输入内容、参数和层选择识别，生成失败保留上次成功结果并标明过期。

新增独立、版本化的处理图项目文件，保存节点、连线、层选择、工件、PMT 布局及视口。PMT 加工导出继续复用现有编译校验、JSON/NPY 契约和发布机制。历史机器目录可通过来源节点加入，新项目保存不覆盖历史加工包。

## 实现边界与验证

处理图模型、层选择解析、依赖执行、编辑历史和画布分别负责独立职责；从 MainWindow 抽出可复用的步骤执行服务，不复制灰度、Hatch 或机器生成算法。

验证重点：全部层和部分层正确传递、稳定层 ID 失效检测、分块侧车保留、循环及类型错误拦截、所选 PMT 的矩阵继承、编号唯一、复制连线重映射、撤销重做、运行快照和缓存失效、项目保存重开。用小 TIFF 完成从导入到独立 PMT 与矩阵加工包的端到端校验，并对现有加工生成测试做回归。

## 需要确认的产品决定

1. Hatch 的“创建单个 PMT”自动插入可见的 Machine 节点。
2. 所选多层默认合为一个 PMT；Machine 对传入层依序进给。
3. “矩阵工件”创建新工件，保留原单个 PMT，矩阵内包含行×列个新实例。
