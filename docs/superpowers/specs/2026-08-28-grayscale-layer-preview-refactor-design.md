# 灰度分层预览稳定性重构设计

## 背景与目标

现有分层预览使用 `ListBox` 数据模板创建多个 Avalonia `Image` 控件，并在选择、刷新和切换时动态替换、释放位图。macOS 崩溃报告显示闪退发生在主线程托管交互链路；此前对 TIFF 解码、资源延迟释放和异常捕获的局部修复没有消除问题。

本次重构保留可点击图片缩略图，但移除 `ListBox + 多 Image + SelectionChanged` 结构。目标是让缩略图点击、连续切层、缩放和重复刷新均不会终止应用，同时保持第 1 步完成后自动展示分层结果。

## 用户界面

主流程预览区继续包含“纹理”“DXF”“分层”三个标签。“分层”标签由以下区域组成：

- 左侧缩略图画布：纵向滚动显示每层缩略图、层号和文件名。缩略图可点击，选中层显示强调色边框。
- 右侧工具栏：上一层、下一层、适应窗口、缩小、放大和 100%。
- 右侧主画布：只显示当前选中层的完整 PNG 预览。
- 底部状态：显示层号、文件名、像素尺寸、缩放比例或单层错误。

第 1 步完成后默认选中第 1 层并自动进入“分层”标签。点击缩略图或上一层/下一层只改变选中索引，不直接释放任何正在绘制的资源。

左侧缩略图区域提供折叠把手。展开时显示图片缩略图、层号和文件名；折叠时收缩为窄栏，只显示可点击的层号按钮，不绘制图片和文件名。折叠/展开只改变左侧布局，不影响当前主图、缩放状态或层选择；选中层号使用强调色标识。

## 组件边界

新增独立的 `GrayscaleLayerPreviewControl`，完整拥有分层预览 UI 和交互，`MainWindow` 不再持有缩略图列表、图片控件、滚动容器或缩放字段。

控件公开最小接口：

- `LoadAsync(directory, previewLoader, cancellationToken)`：扫描并加载一批分层结果。
- `Clear()`：解除可见内容并排队释放资源。
- `Dispose()`：窗口关闭时释放全部资源。
- `HasLayers`：表示是否存在至少一个可预览层。

`GrayscaleLayerPreviewItem` 只保存文件信息、固定的小尺寸缩略图、压缩 PNG 数据、像素尺寸和错误状态。条目不保存当前主图，不参与选择事件。

缩放与点击命中使用无图片依赖的纯状态类：

- `GrayscaleLayerThumbnailLayout`：根据画布宽度、滚动偏移和条目数量计算条目矩形及点击索引。
- `GrayscaleLayerZoomState`：限制缩放范围，计算放大、缩小、100% 和适应窗口比例。

## 缩略图绘制

缩略图区域使用一个自定义 Avalonia `Control` 绘制所有当前可见条目，不为每层创建 `Image`、`Button` 或数据模板。控件根据可视区域只绘制相交条目：

1. 绘制条目背景和选中边框。
2. 使用条目固定缩略图绘制图片区域。
3. 绘制层号和文件名。
4. 根据点击坐标计算目标索引并发送选择请求。

缩略图在整批加载完成后视为不可变资源。选择层时不重建、不替换、不释放缩略图。只有加载新批次或关闭控件时才统一释放。

## 主图切换与资源所有权

每个条目保存 Pillow 转换后的压缩 PNG 数据。选择某层时：

1. 从压缩 PNG 创建候选全尺寸位图。
2. 校验候选位图尺寸。
3. 候选成功后一次性替换主画布的可见位图。
4. 旧主图进入控件内部的延迟释放队列。
5. 在后续 UI 调度周期、且旧图已不再作为可见 Source 后释放。

任何时刻只保留一个当前全尺寸位图和数量受限的待释放位图。缩略图与主图不共享同一个 `Bitmap` 实例。

加载新批次采用两阶段替换：先在临时集合中完成文件扫描、Pillow PNG 转换和缩略图解码；完成后一次性替换可见集合。加载失败或取消时保留当前稳定批次，不暴露半加载状态。

## 数据流与错误处理

```text
第 1 步完成
  -> 后台扫描 layer_*.tiff
  -> Pillow 转换为 PNG 数据
  -> UI 线程解码固定尺寸缩略图
  -> 一次性安装新批次
  -> 选择第 1 层
  -> 解码并显示单一主图
```

所有 Avalonia 位图创建、控件状态变更和绘制失效操作在 UI 线程执行。文件扫描和 Pillow 子进程等待可异步进行。

- 单层转换失败：保留可点击条目并显示错误占位，不影响其他层。
- 主图解码失败：保持当前已显示主图，状态区显示错误。
- 点击或缩放计算异常：在控件边界捕获、记录并显示错误，不向 Avalonia 事件循环抛出。
- 批次取消：释放临时批次，保留旧批次。
- 窗口关闭：先解除可见位图，再释放当前主图、待释放主图和全部缩略图。

## 测试与验收

单元测试覆盖：

- 缩略图矩形布局和点击命中，包括首项、末项、边界外及滚动偏移。
- 选中索引的上一层、下一层和范围限制。
- 缩放上下限、100% 和适应窗口计算。
- 两阶段批次替换在成功、失败和取消时的状态。
- 单层错误不会阻止其他层被选中。

增加压力验证：

- 对 100 个条目连续往返选择至少 1,000 次，选中索引始终正确且无未捕获异常。
- 重复加载和清空批次至少 50 次，资源计数回到稳定值。
- 使用真实分层 TIFF 完成 Pillow PNG 转换、缩略图绘制和主图切换烟雾测试。

验收标准：第 1 步结束后能看到可点击图片缩略图；连续快速点击不同层、使用上一层/下一层、滚轮缩放、按钮缩放和重复执行第 1 步均不闪退；单层损坏只显示错误，不影响应用继续运行。
