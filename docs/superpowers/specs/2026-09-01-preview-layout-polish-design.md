# 预览模块布局优化设计

日期：2026-09-01  
范围：主流程预览区的纹理、DXF 与 PMT 三种视图  
状态：已确认设计方向，待实施

## 背景与目标

当前预览模块的主要问题是顶部工具数量较多且层级分散，PMT 视图的右侧参数栏又因宽度较窄、字段纵向堆叠而显得拥挤。此次优化只调整布局、排版和控件分组，不改变预览内容、选层、缩放、视角、叠加显示或 PMT 参数保存逻辑。

目标如下：

- 建立稳定、统一的预览顶部区域，让三种视图切换时视觉结构不跳变。
- 优先展示高频工具，降低 DXF 专属控制对主工具栏的挤压。
- 提高 PMT 单元信息与参数编辑的扫读效率，并减少无效纵向占用。
- 保持现有主题、键盘与自动化名称体系，避免引入新的交互模式。

## 总体布局

预览模块采用“统一顶部区域 + 当前视图内容”的两段结构。

顶部第一行是稳定的主工具栏：左侧放“纹理 / DXF / PMT”分段切换，右侧放当前视图可用的高频视图操作。缩放操作按“缩小、倍率、放大、适应窗口、实际尺寸”的顺序成组展示；不适用于当前视图的操作隐藏，而不是以大片禁用控件占位。

顶部第二行是上下文工具区，仅在当前视图确有专属操作时显示。纹理视图放图层前后切换、滚轮模式和“切层保持视图”；DXF 视图放图层切换、顶视图/等轴测、滚轮模式、保持视图，以及纹理、填充线、方向箭头和透明度控制。上下文区允许在窄窗口自然换行，但每个语义组内部不拆散。

画布区域继续保留现有左侧图层栏。纹理与 DXF 的图层栏宽度、折叠把手、画布边框、间距和最低高度保持一致。状态文字仍位于画布下方，并与画布左边缘对齐。

## 工具栏信息层级

工具分为三类：

1. 视图切换：纹理、DXF、PMT，固定在第一行左侧。
2. 高频画布操作：缩放、适应窗口与实际尺寸，固定在第一行右侧；PMT 不提供“实际尺寸”时只显示其现有的适应和缩放操作。
3. 内容与导航操作：图层、视角、滚轮策略、保持视图、叠加显示及透明度，进入第二行。

按钮继续复用现有图标与主题样式。图标按钮保留工具提示和自动化名称；模式按钮使用短文字。缩放倍率使用等宽字体，并维持足够宽度，避免数值变化造成工具栏抖动。

DXF 的叠加选项组成独立控制组。透明度标签、滑块只在存在配准纹理时可操作；其他可用性逻辑与现状一致。操作提示不再独占一条显眼的工具行，改为靠近状态区的弱化辅助文字。

## PMT 视图

PMT 视图继续采用“画布 + 右侧详情检查器”，但详情栏调整为约 280 px 的固定宽度，并由三个稳定区域组成：

- 顶部摘要：突出单元编号，下一行显示行列、左上位置和层间进给；JSON 文件名以较弱的等宽文本显示，并允许换行。
- 中部参数：独立滚动。数值参数使用单行横排，左侧为标签，右侧为固定宽度输入框。布尔参数集中到单独分组，减少标签与输入控件交错造成的视觉噪声。
- 底部操作：状态提示位于按钮上方；“保存覆盖”和“还原基础”采用图标加文字按钮，固定在底部，不随参数列表滚动。

未选择单元时，顶部显示明确的选择提示，参数区保持禁用，底部按钮不可用。选择、切换或清空布局时，沿用现有参数装载和状态重置规则。

## 组件边界与数据流

`MainWindow` 继续负责三种预览的组合与选中状态；共享顶部区域由预览容器统一组装。纹理与 DXF 控件继续负责各自画布和图层导航，不改变文件加载或视图状态模型。

`PmtDetailsEditor` 只调整内部布局：现有 `LoadJob`、`CollectValidParameters`、`SaveRequested` 和 `ResetRequested` 契约保持不变。`PmtPreviewControl` 的选择、平移、缩放与绘制逻辑不变。

为了避免一次性扩大重构范围，第一版不抽象新的通用预览基类。共享布局通过小型工具栏构建方法或明确的控件分组完成，现有纹理与 DXF 宿主仍各自维护其行为。

## 响应式与可访问性

- 第一行保持单行；宽度不足时优先压缩中间留白，不拆分预览切换组和缩放组。
- 第二行可按语义组换行。滑块保持可用的最小宽度，不与文字逐项交错换行。
- PMT 检查器保持固定目标宽度；主窗口较窄时仍优先保证画布最小宽度，必要时由现有工作区分隔行为承担空间调整。
- 所有现有自动化名称、工具提示、焦点能力和主题对比度语义继续保留；新增文字按钮需提供明确自动化名称。
- 选中、禁用与错误状态不能只依赖颜色，继续使用勾选、描边、按钮状态和文字提示表达。

## 错误与状态处理

本次不改变错误来源或业务处理。纹理/DXF 加载失败仍显示在各自状态区；PMT 参数范围错误仍显示在详情栏底部状态区。布局调整必须保证长错误文本可换行，且不会覆盖固定操作按钮。

切换预览标签不清空任何已加载内容。DXF 控件可用性、PMT 未选择态和保存成功/失败状态均沿用现有逻辑。

## 验证范围

实施后需要验证：

- 三种预览切换时，顶部结构、画布边界和整体高度稳定。
- 常规窗口宽度与较窄宽度下，工具组不会互相覆盖，第二行按组换行。
- 纹理与 DXF 的上一层、下一层、缩放、适应窗口、实际尺寸、滚轮模式和保持视图行为不变。
- DXF 顶视图、等轴测、叠加开关、透明度和方向箭头行为不变。
- PMT 选择、切换、清空、编辑、范围错误、保存和还原行为不变；底部操作始终可见。
- 浅色与深色主题下检查文字对比、边框层级、焦点状态和禁用状态。
- 更新或补充结构测试，并运行现有 Avalonia 测试套件。

## 非目标

- 不改变主工作区左右分栏比例或日志栏结构。
- 不修改预览渲染算法、图层数据结构、DXF 解析或 PMT 文件格式。
- 不新增弹窗、抽屉、“更多”菜单或用户偏好设置。
- 不重新设计全局主题、检查器表单或主流程按钮。
