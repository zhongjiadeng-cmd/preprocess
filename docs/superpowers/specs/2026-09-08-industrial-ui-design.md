# 工业工作台界面统一

用户要求：节点工具与软件整体朝专业工业软件方向优化。外观保留跟随系统，深浅两套界面统一。

采用冷灰浅色、石墨灰深色，统一语义画刷。紧凑工具条、32px 控件、4–6px 圆角、清晰边界；蓝色表示选择、焦点和主要操作。保留中文字体回退与文字对比度。

全局：收紧窗口标题、页签和工作区留白，原有加工流程与节点工具使用同一套控件和容器规则。主题偏好及系统跟随行为保留。

节点：标题含类型缩写标识；端口、内容与运行状态分区；参数摘要使用标签和值，真实图片在独立预览区域适配；工件使用带坐标方向的工作区。画布保留独立移动、调整大小、多选、快捷键和层选择。

工作流工具条区分项目文件、添加节点、编辑视图和执行操作。检查器采用紧凑标签/输入行与明确分组，低频布局设置折叠。状态条显示运行反馈。

验证：全量既有 C# 回归、真实加工集成、实际 Avalonia 界面的拖线/拖动/缩放/撤销/剪贴板验证；导出深浅主题的节点工作流和原有加工流程，以及小窗口截图检查布局。更新 Mac 应用。
