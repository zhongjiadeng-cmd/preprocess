# 移除弹窗外层灰色框：设计规格

## 目标

移除“导入”“外观”和“单步执行”三个 Flyout 最外层由 Avalonia Fluent 主题绘制的灰色背景框，同时保留 `UiTheme.FlyoutSurface` 提供的内部弹窗背景、圆角、描边、间距以及现有交互状态。

## 方案

在应用的共享主题资源中统一覆盖原生 Flyout presenter 的外壳资源，使 presenter 背景和边框透明，并将外层边框厚度与内容留白归零。三个 Flyout 继续使用现有的 `UiTheme.FlyoutSurface`，不分别添加局部修补。

若 Avalonia 11.3.18 的资源键不足以消除模板留白，则补充一个仅针对 `FlyoutPresenter` 的共享样式；不替换原生 Flyout，不改变定位、失焦关闭或键盘交互。

## 范围

- 修改共享 Flyout 外壳样式或资源。
- 为关键视觉属性增加回归测试。
- 验证现有测试与项目构建。

不修改内部菜单项尺寸、选中态、焦点环、颜色语义、弹出方向或业务行为，也不影响 ComboBox 下拉菜单。

## 验收标准

1. 三个截图所示弹窗不再出现最外层灰色圆角矩形。
2. 内层深色圆角弹窗及其细描边仍然存在。
3. 深色与浅色主题均无额外外壳底色。
4. Flyout 的定位、点击外部关闭、单选和按钮点击行为保持不变。
5. 自动化测试和项目构建通过。

## 风险与验证

主要风险是覆盖范围误伤 ComboBox，或透明外壳仍保留模板 padding。实现应优先使用 Flyout 专属资源/样式，并通过测试确认 ComboBox 资源未改变；构建后对三个入口进行视觉检查。
