# 曲面黑区平行阴影线预览设计

## 目标

更新现有三维交互预览，使用 `layer_06_gray_lt_128.tiff` 作为模型纹理，并增加“平行阴影线”黑区表现方式。阴影线只存在于纹理黑色区域内；阴影线穿过 OBJ 三角网格边界时建立几何断点，但相邻线段端点保持重合，因此视觉连续且各段分别贴合所在三角面。

## 输入与只读约束

- 三维模型继续使用 `/Users/ccc/Downloads/data/surf.exported.obj`。
- 新纹理使用 `/Users/ccc/Desktop/preprocess/layer_06_gray_lt_128.tiff`。
- 新纹理为 5326 × 5326 的 8 位灰度二值图，与模型现有 UV 位于相同纹理空间。
- 黑区判定固定为灰度值小于 128；当前输入中黑区约占 18.34%。
- 不修改、覆盖或重写源 OBJ、源 TIFF 或用户提供的附件页面。

## 方案选择

采用“UV 空间裁剪，三角面内重建”的真实几何阴影线方案。

不采用仅在片元着色器中模拟阴影线的方案，因为它不能保证断点准确落在 OBJ 三角网格边界。不采用固定阴影线贴图烘焙，因为它无法表达逐三角面分段，也不方便在浏览器内调节角度和间距。

## 阴影线生成

生成阶段将二值纹理缩小为适合交互预览的无损蒙版，并建立 UV 三角形查找数据。浏览器根据当前角度和间距在 UV 平面生成等距平行扫描线。

对每条扫描线：

1. 只保留落在灰度值小于 128 区域内的区间。
2. 判断每个连续采样点所属的 OBJ UV 三角形。
3. 当所属三角形改变时，在两三角形公共边界位置结束当前线段并开始下一线段。
4. 使用对应三角面的 UV 重心坐标，将每个端点插值到三维顶点位置。
5. 沿插值法线施加极小表面偏移，避免阴影线与曲面发生深度闪烁。

相邻三角面上的线段共享同一边界端点，不插入空白间距。这里的“断点”是几何分段点，而不是肉眼可见的缺口。

UV 三角形查找使用生成阶段构建的紧凑三角形索引图。若少数边缘采样点因为栅格精度无法取得三角形，则跳过该点并终止当前小段，避免错误连接到模型另一侧。

## 显示与交互

黑区表现提供两种状态：

- 原始实心：直接显示新 TIFF 的黑白纹理。
- 平行阴影线：曲面底色保持明亮，只用平行线填充原纹理黑区。

三角网格作为独立开关，可与任一黑区表现同时使用。保留拖动旋转、滚轮缩放和复位视角。

新增或保留的参数：

- 阴影线角度：默认 45°，允许连续调节。
- 阴影线间距：控制填充密度，并限制最小值以避免生成过多线段。
- 阴影线强度：控制线条透明度；WebGL 原生线宽不可靠，因此不承诺精确像素宽度。
- 三角网格显示与强度。
- 凹凸强度：仅在“原始实心”状态影响纹理材质；平行阴影线状态不改变真实几何轮廓。

改变角度或间距时在浏览器中重新生成阴影线，并使用一次动画帧合并连续滑块输入，避免重复计算阻塞界面。

## 数据与组件边界

- 生成器负责解析 OBJ、压缩顶点/法线/UV/面索引、生成无损黑区蒙版和 UV 三角形索引图。
- 曲面材质组件负责原始实心纹理、灯光和可选凹凸。
- 阴影线生成组件负责扫描黑区蒙版、检测三角形切换、重心插值和输出三维线段。
- 三角网格组件继续使用 OBJ 三角边生成独立线层。
- 交互状态只包含黑区表现、角度、间距、阴影线强度、三角网格状态、凹凸和相机状态。

所有几何和纹理预览数据内嵌到线程专属 HTML 片段。页面不使用 `fetch`、XHR、WebSocket 或本地绝对资源引用，最终片段保持小于 1 MB。

## 错误处理

- OBJ 缺少 UV、法线或三角面时，生成阶段停止并报告具体原因。
- TIFF 无法解码或尺寸无效时，不生成空白预览。
- UV 三角形退化时忽略该三角形，并在统计信息中报告数量。
- 阴影线参数限制在安全范围；当计算结果为空时显示“当前参数未生成阴影线”，而不是保留旧结果。
- Three.js、WebGL 或内嵌资源初始化失败时，在预览区域显示可读错误。

## 验证

自动验证至少覆盖：

1. 新 TIFF 被识别为 5326 × 5326 二值灰度图，黑区阈值使用 128。
2. 默认 45° 阴影线只落在黑区，不出现在白区。
3. 一条阴影线跨越三角形边界时被拆成多个线段，公共端点三维坐标在容差内重合。
4. 每个输出端点的重心坐标有效，映射后的点位于对应三角面上。
5. 调整角度和间距会改变线段集合，安全下限能限制最大线段量。
6. “原始实心 / 平行阴影线”切换、三角网格开关、强度、凹凸和复位操作有效。
7. HTML 小于 1 MB，不包含被禁止的运行时读取方式或本地源路径。

浏览器验证覆盖 736 px 和 360 px 宽度，检查默认视角、两种黑区表现、三角网格叠加、角度与间距变化、旋转缩放、复位以及控制区无重叠裁切。

## 验收标准

- 模型表面使用 `layer_06_gray_lt_128.tiff` 的黑白六边形纹理。
- 平行阴影线只填充黑色六边形及圆形边缘中的黑区。
- 阴影线在每个 OBJ 三角网格边界形成真实几何分段，视觉上没有人为间隙。
- 用户能够调节角度、间距和线条强度，并独立显示或隐藏三角网格。
- 预览保持可旋转、可缩放、可复位，源文件保持不变。
