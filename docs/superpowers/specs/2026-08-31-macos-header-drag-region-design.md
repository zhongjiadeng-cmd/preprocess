# macOS 顶部栏拖动区域设计规格

## 目标

在主窗口采用一体化标题栏后，让顶部应用栏中的非操作区域可以正常拖动窗口，同时保证右侧“导入、清理、外观”等工具继续响应点击。

## 方案

将顶部栏左侧品牌区与中间剩余空白区组成专用拖动区域。该区域仅在鼠标主键按下时调用 Avalonia 原生 `Window.BeginMoveDrag`，由系统继续处理窗口移动。

右侧工具组不放入拖动区域，不依赖事件冒泡过滤按钮；因此工具点击、Flyout 展开、键盘操作和辅助功能语义保持不变。红黄绿原生窗口按钮继续由 macOS 管理。

## 范围

- 调整顶部栏内部布局，使品牌与空白区域形成明确的拖动表面。
- 增加鼠标主键判断与原生拖动调用。
- 增加布局与事件接入回归测试。
- 重新构建并打开 macOS 应用。

不改变顶部栏高度、窗口按钮、右侧工具、主题、业务功能或其他窗口。

## 验收标准

1. 按住顶部品牌区或其右侧空白区域可拖动窗口。
2. 右侧“导入、清理、外观”仍可正常点击和展开。
3. 右键或其他非主键操作不会开始拖动。
4. 红黄绿窗口按钮保持原生行为。
5. 自动化测试和应用构建通过。

## 风险与验证

主要风险是拖动命中区覆盖操作控件。实现通过布局隔离而非控件类型过滤来避免该问题；测试检查拖动处理器只绑定到专用区域，构建后手动验证拖动和三个工具入口。
