# HTML 三维纹理与网格线预览设计

## 目标

为用户提供的 `surf.exported.obj`、`surf._U1_V1_e.tif` 创建一个可在对话中直接操作的三维预览，用于观察规则立方/蜂窝明暗纹理贴到模型后的效果，并可切换显示模型自身的三角网格线。

## 范围

预览使用 OBJ 中现有的顶点、法线、三角面和 UV。源 OBJ 与 TIFF 保持只读，不修改、不覆盖，也不生成新的生产模型文件。

预览支持三种显示状态：

- 仅显示网格阴影纹理。
- 同时显示纹理与 OBJ 三角网格线。
- 仅显示 OBJ 三角网格线。

用户可拖动旋转模型、滚轮缩放，并调节三角网格线粗细、纹理明暗和视觉凹凸强度。

## 实现方案

使用 Three.js 渲染真实模型。为满足对话内 HTML 小于 1 MB 且不得运行时读取本地文件的限制，在生成阶段完成以下处理：

1. 解析 OBJ，提取实际使用的顶点位置、法线、UV 和三角面。
2. 合并可安全复用的顶点数据，并对数值精度做仅面向预览的压缩。
3. 将 5326 × 5326 灰度 TIFF 缩小并编码为轻量的内嵌预览纹理；UV 位置和纹理比例保持不变。
4. 将压缩后的几何数组和纹理以页面内数据形式写入 HTML，不使用 `fetch`、XHR 或外部本地资源。
5. Three.js 从允许的固定版本 CDN 加载，页面本身保持为对话可嵌入的 HTML 片段。

不使用原始 76 MB TIFF 直接内嵌，因为它会使预览加载和交互明显变慢。缩小纹理只降低近距离观察时的细节清晰度，不改变贴图覆盖方式。

## 视觉与交互

默认进入“纹理＋三角网格线”状态，并从能看清模型整体曲率的斜前方视角展示。场景使用中性背景、柔和环境光和一盏方向光；材质保留灰度纹理，不额外引入彩色效果。

控制区保持紧凑，包含：

- 三态显示模式选择。
- 三角网格线粗细。
- 纹理明暗对比。
- 凹凸强度。
- 复位视角。

拖动和滚轮操作直接作用于模型视角。控件使用原生表单元素，支持键盘操作，并在窄屏下自动换行。

三角网格线使用独立线段层叠加在模型表面，通过轻微深度偏移避免闪烁。线宽受 WebGL 实现限制时，以线条透明度和深浅共同表达强弱；界面不会声称提供浏览器无法保证的精确物理像素宽度。

凹凸效果采用片元着色中的视觉法线扰动或材质近似，只用于判断质感，不改变模型轮廓，也不作为可制造的真实位移结果。

## 数据流与组件

- 生成脚本负责读取源文件、转换纹理、压缩几何并写出 HTML 片段。
- 场景初始化负责创建相机、灯光、纹理材质、线框层和模型包围盒适配。
- 交互控制负责旋转、缩放、模式切换和参数更新。
- 状态提示负责在 WebGL、Three.js 或数据初始化失败时显示明确错误。

各部分通过简单状态对象共享显示模式和三个参数，不读取或修改工作区中的业务应用状态。

## 错误处理

- OBJ 缺少必要的面或 UV 时，生成阶段停止并报告具体问题。
- 纹理解码失败时不生成空白预览。
- Three.js 加载失败或浏览器不支持 WebGL 时，在预览区域显示可读错误。
- 参数输入限制在安全范围内，避免出现不可见模型或异常着色。

## 验证

生成后至少检查：

1. HTML 片段小于 1 MB，且不包含 `fetch`、XHR 或本地绝对资源引用。
2. 几何顶点、三角面与 UV 数量合理，模型可见且比例正确。
3. 三种显示状态均能切换，纹理与三角线框覆盖同一模型。
4. 拖动旋转、滚轮缩放、参数滑块和视角复位有效。
5. 736 px 与 360 px 宽度下控件和画面不重叠、不裁切。
6. 初始化错误能显示文本提示，而不是留下空白区域。

## 验收标准

- 用户能直接旋转并观察纹理贴到真实模型后的总体效果。
- 用户能在“仅纹理”“纹理＋网格线”“仅网格线”之间切换。
- 明暗、凹凸和网格表现可调，默认状态清晰可辨。
- 预览加载体积受控，不修改任何源模型或源纹理文件。
