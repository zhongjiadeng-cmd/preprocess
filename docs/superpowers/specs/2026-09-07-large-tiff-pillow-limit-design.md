# 大尺寸 TIFF 导入像素限制调整

## 目标

允许当前项目导入约 9900 万像素的可信 TIFF 文件，避免 Pillow 因默认
`DecompressionBombWarning` 阻止或干扰正常流程，同时保留对异常超大图片的基本保护。

## 现状

项目有两个直接使用 Pillow 打开输入 TIFF 的 Python 入口：

- `grayscale_layers.py`：灰度图分层流程。
- `texture_to_hatch_dxf.py`：纹理转 Hatch DXF 流程及图像检查/预览。

当前输入 `火花纹COL001214.tif` 的尺寸为 `10536 × 9399`，共 `99,027,864`
像素，超过 Pillow 默认的 `89,478,485` 像素安全阈值。

## 方案

在上述两个入口导入 Pillow 后，将 `Image.MAX_IMAGE_PIXELS` 设置为
`120_000_000`。这个上限覆盖当前文件并保留约 21% 余量；不设置为 `None`，
以继续拦截明显异常的超大图像。

该设置只影响项目自身 Python 进程，不修改用户环境中的 Pillow 安装，也不改变
图像内容、尺寸或输出格式。

## 错误处理与资源考虑

该调整只解除像素数量检查，不降低图像解码所需的实际内存。当前图像为 8-bit
灰度图，后续 NumPy 转换和分层输出仍可能产生额外内存占用。若未来处理更大的
图像，应继续评估内存峰值，而不是无限提高全局上限。

## 验收

1. 两个 Python 入口都使用相同的 `120_000_000` 像素上限。
2. 使用 `火花纹COL001214.tif` 打开并读取灰度数据时不再产生
   `DecompressionBombWarning`。
3. 现有 Python 测试仍通过，且不修改无关文件。
