# 单层 Hatch 填充角度设计

## 背景

主流程当前把第一个分层文件的索引 `0` 乘以“层间角度递进”，因此只生成一层 DXF 时，填充角度始终为 `0°`。用户希望单层任务直接使用“层间角度递进”的设置值，同时保持多层任务的现有角度序列不变。

## 行为规则

- 当总层数为 `1` 时，唯一一层的填充角度为设置的“层间角度递进”值，并继续按 `180°` 循环。
- 当总层数大于 `1` 时，维持现有规则：第 1 层为 `0°`，第 2 层为一个递进值，第 3 层为两个递进值，依此类推，并按 `180°` 循环。
- 此变更只影响“三步流程”中的逐层 Hatch DXF 生成，不改变独立“纹理转 Hatch DXF”页面的角度行为。

例如递进值为 `45°`：

- 生成一层时：`45°`。
- 生成四层时：`0°、45°、90°、135°`。

## 实现

在 `GrayscaleLayersMac/MainWindow.cs` 现有逐层循环的角度计算处增加总层数判断：单层使用递进值，多层继续使用从零开始的层索引乘以递进值。两条分支均对 `180°` 取模，然后将结果继续通过现有 `--angle` 参数传给 `texture_to_hatch_dxf.py`。

不新增配置项、不改变界面标签，也不修改 Python Hatch 算法。

## 测试与文档

先在现有 Python 测试套件中增加 C# 源码契约测试，验证：

- 角度计算显式区分单层和多层。
- 单层分支直接使用递进值。
- 多层分支仍使用零起始索引乘以递进值。
- 最终角度仍按 `180°` 循环。
