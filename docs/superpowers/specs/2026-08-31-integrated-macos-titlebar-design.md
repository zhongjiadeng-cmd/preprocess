# macOS 一体化标题栏设计规格

## 目标

移除主窗口顶部独立的原生标题栏背景与居中标题，将 macOS 原生红黄绿窗口按钮融入现有应用顶部栏。窗口仍需保留关闭、最小化、全屏、拖动和系统辅助功能。

## 方案

主窗口启用 Avalonia 的扩展客户区，并使用无独立标题栏的原生装饰模式。现有 `appHeader` 继续作为唯一可见顶部表面，同时为左侧原生窗口按钮预留安全区，使应用图标、名称与按钮互不遮挡。

标题栏的可拖动区域由扩展客户区覆盖；顶部栏内的导入、清理和外观控件仍保持可点击。原生窗口按钮由 macOS 管理，不自绘、不改写窗口命令。

## 范围

- 修改 `MainWindow` 的客户区与标题栏配置。
- 调整顶部应用栏左侧间距。
- 增加窗口配置和布局回归测试。
- 重新构建 macOS 应用并验证。

不修改业务工具排列、顶部栏高度、窗口最小尺寸、主题颜色、其他进度窗口或文件选择对话框。

## 验收标准

1. 截图红框所示独立灰色标题栏与居中标题不再出现。
2. 红黄绿原生窗口按钮保留并位于应用顶部栏内。
3. 应用图标和名称不被窗口按钮遮挡。
4. 顶部栏可用于拖动窗口，右侧工具仍可正常点击。
5. 关闭、最小化、全屏及系统快捷键行为保持原生。
6. 深色与浅色主题均只显示一层连续顶部栏。

## 风险与验证

主要风险是不同 macOS 缩放比例下安全区不足，或交互控件被误当作拖动区域。实现使用固定的 macOS 标准按钮安全宽度，并保留控件自身命中测试；构建后检查窗口按钮、品牌区、工具区和拖动行为。
