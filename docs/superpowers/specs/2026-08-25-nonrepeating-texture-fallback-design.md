# 无重复周期灰度图回退设计

## 目标

当 `texture_to_hatch_dxf.py` 以默认 `unit` 模式处理无法可靠识别横向或纵向重复周期的灰度图时，不再终止转换，而是把整张输入灰度图作为填充源，按现有 `repeat` 规则适配到目标尺寸并继续生成 DXF。

能够可靠识别二维重复周期的输入仍使用现有“提取最小重复单元、仅放置完整单元”行为。

## 行为

1. `unit` 模式首先调用现有 `detect_repeating_unit`。
2. 仅当周期检测报告“无法可靠识别横向/纵向最小重复周期”时，回退到 `fit_texture_to_size(..., tile_mode="repeat")`，使用完整输入图。
3. 回退时输出明确日志，说明未识别到重复周期，已改用完整输入图；后续的阴影线角度、Voronoi 分块和随机种子逻辑保持不变。
4. 尺寸过小、DPI 缺失、参数非法或其他处理错误仍按原样报错，不得被回退逻辑吞掉。
5. 显式 `repeat` 与 `mirror` 模式保持不变。

## 实现边界

周期检测使用一个专用异常类型表示“无可靠重复周期”。`_detect_axis_period` 的两个方向检测失败都抛出该类型；转换入口只捕获这一类型并执行完整图回退。这样可以避免通过匹配中文错误文本判断，也避免误吞其他 `ValueError`。

回退沿用现有 `fit_texture_to_size`，不增加缩放算法或新的 UI 设置。目标区域小于输入图时按现有锚点裁剪；目标区域大于输入图时按完整输入图周期铺设后裁剪。

## 测试

- 构造一个确定没有二维重复周期的二值图，验证默认 `unit` 转换成功并走完整图路径。
- 验证回退日志明确出现，且不再打印“自动识别最小重复单元”。
- 验证周期性输入仍走最小重复单元路径。
- 验证与周期无关的错误不会触发回退。
- 运行完整 Python 测试套件，并用本次实际 TIFF 做一次端到端转换验证。
