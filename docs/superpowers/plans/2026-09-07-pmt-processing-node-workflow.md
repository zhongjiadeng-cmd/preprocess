# PMT 处理图实施计划

采用已确认的 2026-09-07 设计，在现有 Avalonia 应用中实现。

1. 新增独立版本化处理图：类型化节点、按连接选择层、拓扑校验、矩阵模板与稳定编号。
2. 实现快照编辑历史、复制粘贴和项目持久化；编辑不会删除加工结果。
3. 新增可取消的处理服务，调用现有 Python 脚本，保留层序、分块侧车及独立 PMT 导出契约。
4. 新增无限画布与检查器，支持导入、拖动连线、层多选、矩阵、快捷键、运行状态、保存和打开。
5. 将节点工作流作为主入口，保留原流程供已有项目使用。
6. 验证图模型、历史、复制、矩阵、执行失效与输出；运行现有 C# / Python 测试并检查界面。
