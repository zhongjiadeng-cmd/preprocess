# 加工文件末条 G90 换行试验

2026-09-09：普通加工导出及 LaserPMT 导出统一将末条字符串从 `G91G00…F40G90` 改为 `G91G00…F40\nG90`。

JSON 文本中的 `\n` 是换行的转义表示；JSON 解码后为实际 LF 换行，使相对运动与恢复绝对模式处于两个程序段。位移计算、参数与 patch 引用不变，既有加工文件不自动修改。

生成校验和 PMT 基础文件读取现在要求末条使用该换行格式，拒绝旧的同一行 G91/G90。旧加工包作为 PMT 输入前需要重新生成。

自动化测试验证单块、多块、JSON 往返及拒绝同一行模式冲突。接收软件是否支持字符串内多个程序段仍需实机验证；本地模拟不证明控制器执行行为。
