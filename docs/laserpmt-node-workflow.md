# LaserPMT 节点工作流

LaserPMT 的第 4 步使用可编辑节点图作为生成输入。导入或生成基础加工目录后，应用会读取基础 PMT 的实际尺寸与全部可编辑参数，创建基础参数节点和初始 PMT 布局。

## 使用方法

1. 在左侧设置工件宽高、PMT 数量、每行数量、编号格式和时间戳 Hatch 间距。
2. 点击“按左侧配置重建”创建初始图。重建会清除当前图上的手动位置、节点与连线。
3. PMT 可在工件内单独拖动；选中后可按 Delete，或在右侧属性栏删除。删除不会重排或复用编号。
4. 从工具栏选择参数并添加单参数节点。在属性栏输入逗号分隔的值；节点右侧会生成稳定的编号端口。
5. 从某个编号端口拖线到 PMT 或时间戳。同一端口可以扇出连接多个目标；同一目标的同一参数只能有一个单参数输入。
6. 选中基础参数节点可停用某项基础参数。停用后，每个加工目标都必须通过单参数节点获得该参数，否则第 4 步会阻止生成。
7. 点击“+ 时间戳”加入本地时间 `MMddHHmm`。时间戳可拖动，右下角可缩放；属性栏可编辑 8 位文本和尺寸。

画布支持滚轮缩放、拖动空白处平移、“适应全部”和“自动排列 PMT”。PMT 与时间戳必须完整位于工件内，且不能有正面积重叠；边缘接触允许。

## 输出与兼容性

版本 2 的 `pmt-layout.json` 同时保存节点图、稳定 ID、端口与连线、编译后的每目标参数、视口、编号状态和生成元数据。Python 生成器会独立重编译并核对节点图，避免只信任前端结果。

加工顺序固定为：所有 PMT 按编号升序，然后所有时间戳按创建顺序。PMT 继续生成独立的 `pmt_xxxxmachine.json`；时间戳只进入 `allmachine.json`、`parameter-map.csv` 和布局文件，并生成水平横线填充的 `<f4` NPY。旧版版本 1 布局模型仍保留只读解析能力。
