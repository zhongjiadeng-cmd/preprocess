# 纹理预处理工具（macOS）

这是一个 C# / Avalonia 图形界面，包含三个功能页：

- 主流程（三步）：先生成灰度分层 TIFF，再识别每一层的最小重复单元并将完整单元阵列转换为同名 Hatch DXF，最后打包为机器加工文件。
- 应用图标：灰度分层轮廓过渡为蓝色 Hatch 扫描线，并以金色箭头表示加工方向。
- 灰度图分层：调用 `grayscale_layers.py`，按累计阈值输出多张黑白 TIFF。
- 纹理转 Hatch DXF：调用 `texture_to_hatch_dxf.py`，裁剪/平铺纹理并将黑区输出为指定角度的阴影线。

应用默认打开主流程，原有两个独立功能页仍然保留。主流程依次输出灰度分层 TIFF、分层 Hatch DXF 和机器加工文件。算法会检测横向和纵向最小周期、寻找切割最少的单元边界，并在目标区域内仅放置整数个完整重复单元；不能容纳完整单元的边缘空间保持空白。主流程和“纹理转 Hatch DXF”页面均提供 Voronoi 参数区，可以设置加工块数量、单块面积范围、边界扩散宽度、连续变化长度和随机种子。

Hatch DXF 默认被划分为 9 个面积受约束的 Voronoi 加工块，内部共享边界使用连续随机扰动产生自然毛边，最外层加工边界保持不变。DXF 实体按块连续输出，每个块内部按扫描方向排列。主流程可设置“层间角度递进”：第 1 层固定为水平 0°，第 `i` 层角度为 `i × 递进角度`（按 180° 循环）。可选“往返填充 Hatch”，使相邻扫描行的线段方向交替。实际 DXF 阅读器以箭头显示线段方向；最终精确面积以生成日志为准。

生成完成后，“实际 DXF 预览”会读取输出文件中的 LINE 实体并自动适应画布，也可通过“导入 DXF…”直接预览已有文件；在主流程中，导入文件会加入层选择器。DXF 内容保持原有极简格式；阅读器根据“块内线段从上到下、各块连续输出”的实体顺序，在 Y 坐标重新回到高处时推断新加工块，并用不同颜色显示。“显示方向箭头”默认开启，每条可见线段的起点和终点均显示黄色方向箭头，两个箭头都表示 DXF 起点到终点的方向；取消勾选可隐藏箭头。支持鼠标滚轮缩放、左键拖拽平移和“适应窗口”。缩小时会合并落在同一屏幕像素范围内的扫描行，放大时自动恢复细节。三步批处理期间，已完成的 DXF 会逐项加入层选择器，可随时切换查看任意单层。超大文件会均匀抽样显示，以保持界面响应。

命令行可通过 `--blocks`、`--min-block-area`、`--max-block-area`、`--boundary-blur`、`--boundary-correlation` 和 `--seed` 调整分块。使用 `--blocks 0` 可关闭分块并恢复单幅面输出。例如：

```bash
python3 texture_to_hatch_dxf.py input.tiff output.dxf \
  --size 100 --blocks 9 \
  --min-block-area 500 --max-block-area 1800 \
  --boundary-blur 3 --boundary-correlation 1 --seed 12345
```

## 机器加工文件

主流程会将分层 Hatch DXF 打包为机器加工文件。启用 Voronoi 分块的 DXF 会生成同名 `*.blocks.json` 侧车文件；该文件只在机器加工打包阶段使用。页面中的“层间下降深度”默认固定为 **3 μm**，最小为 **0.5 μm**，可直接编辑；更小的深度无法在 0.001 mm 的机器坐标中表达为非零移动。机器 Z 每层只下降一次，而不是每个加工块下降一次。

“按加工块中心移动 XY”复选框默认勾选；加工块数量为 `0` 时该复选框不可用，但会保留已选状态，恢复正数块数后继续使用。分块 patch 内部使用局部 XY 坐标，机器 XY 使用相邻加工块中心之间的连续相对增量。检查边框仍保留在 DXF 中，但不会写入分块 patch。加工处理以 `G91` 开始、结束时恢复 `G90`，且不会回到原点。

只有第一组激光参数的全部字段可编辑；第 2、3 组激光参数保留为参考值。机器加工目录创建在 DXF 目录的同级目录中；名称留空时自动使用 `machine_file_时间戳`。若同名最终目录、工作目录或锁文件已经存在，程序不会覆盖它们。第三步开始前会核对本次生成的 DXF 清单；取消第三步时，只有锁文件中的所有权令牌与本次任务完全一致，程序才会清理对应的临时目录和锁文件。

输出目录结构如下：

```text
共同父目录/
├── 30X30-40C-240u-FK_dxf/
│   ├── layer_01_....dxf
│   └── ...
└── machine_file_YYYYMMDD_HHMMSS/
    ├── machine.json
    └── patches/
        ├── 0_0.npy
        ├── 1_0.npy
        └── ...
```

## 开发运行

```bash
cd GrayscaleLayersMac
dotnet run
```

运行前需要安装 Python 3 依赖：

```bash
python3 -m pip install numpy pillow
```

## 发布 Apple Silicon 版本

```bash
dotnet publish -c Release -r osx-arm64 --self-contained true
```

Intel Mac 将运行时标识改为 `osx-x64`。
